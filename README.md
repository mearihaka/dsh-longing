# dsh-longing（暗涌）

给 DeepSeek Harness 加一层「欲望状态」：性欲 / 色情 / 占有 / 羞耻 / 理智 / 疲劳，随时间衰减、睡前走高，并按状态影响角色的说话与主动性。

**插件本身不绑定任何聊天平台**。它只做三件事：维护状态、渲染面板、生成一段可以直接拼进系统提示的文本。谁来收发消息，由你自己接。

## 它是什么

- 一个 DSH 插件（`dsh.bundle` 挂载）：状态、衰减、高峰、面板、注入文本；
- 面板由插件自己用 DSH 的 `webServer` 提供：`http://127.0.0.1:<DSH端口>/dsh-longing`
- 状态文件 `欲望状态.json`（纯文本，可手改），路径默认 `workspace/`，可配置。

## 六个值

| 键 | 含义 | 默认 |
|---|---|---|
| `lust` | 性欲：多想要、多主动 | 30 |
| `lewd` | 色情值：露骨程度 | 35 |
| `possess` | 占有值：病娇浓度 | 55 |
| `shame` | 羞耻度：越高越欲拒还迎 | 45 |
| `resist` | 理智：越高越克制 | 50 |
| `fatigue` | 疲劳：高时欲望转成想被抱 | 20 |

`lust ≥ 40` 进入亲密语气，`≥ 60` 主动，`≥ 80` 发情。

## 三种接入方式（选一个就行）

### 1. 读文件（最省事，不写代码）

插件每分钟把当前该注入的文本写到：

```
<状态目录>/欲望注入.txt
```

你的 bot 插件只要在拼系统提示时读这个文件拼进去即可。空文件 = 当前不该注入（欲望低 / 暂停 / 时段外）。

```js
const block = readFileSync(injectPath, 'utf8').trim()
if (block) systemPrompt += '\n' + block
```

主动开口也可以走文件：面板里把「主动通道」设为 `file`，她会把要说的话追加到 `待发消息.txt`，你的 bot 轮询取走发送。

### 2. 取服务（插件作者）

```js
const desire = ctx.get('desire')
if (desire) {
  systemPrompt += '\n' + desire.block()
  const s = desire.state()   // { lust, lewd, ... }
}
```

### 3. 直接发（OneBot HTTP）

面板里「主动通道」选 `http`，填 OneBot HTTP 地址和 token、主人 ID。她会自己调 `/send_private_msg`。

## 面板

由插件自带，打开：

```
http://127.0.0.1:<DSH端口>/dsh-longing
```

首次打开要粘贴令牌，令牌在状态目录的 `面板令牌.txt`（只在本地）。

面板里能改：六个值、场景、高峰时段、衰减、主动参数、通道、生图后端、人设补丁、安全设定（只对主人生效、安全词、暂停）。

**优先级**：面板 > DSH 插件设置 > 代码默认值。被面板覆盖的字段会有橙边，点「恢复默认」清空覆盖。

## 生图后端（可选）

面板里可以配 ComfyUI 地址、启动脚本、自动拉起。探测不到时不会报错，注入文本会改成「图床没开」，聊天照常。

## 配置

DSH 插件设置里能改全部字段（见 `src/config.js`）；面板改的值优先。

## 隐私

- 状态、历史、注入文本都是明文 JSON/文本，放在本机；
- `.gitignore` 已排除运行期文件；
- 面板有令牌 + Origin 校验，只绑回环地址。
