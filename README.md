# dsh-longing（暗涌）

给 DeepSeek Harness 加一层会自己流动的「欲望状态」：性欲、色情值、占有、羞耻、理智、疲劳、好感。
数值随时间衰减、睡前走高、聊天会推高，最后变成一段**只给模型看的内心状态**，影响它说话的密度、主动程度和收不收着。

插件**不绑定任何聊天平台**。它只做三件事：维护状态、提供一个网页面板、把状态渲染成一段可以直接拼进提示词的文本。谁来收发消息，由你的通道插件决定。

---

## 一、它有什么用

一句话：**让角色「有今天」**。

没有这层东西时，模型每次回复都从同一个基线出发——昨天刚亲过，今天第一句话还是客客气气；半夜三点和下午三点说话一个语气；你哄十句和冷落三天，它的态度不变。

有了这层东西：

- 它会**累**。熬夜到两点，欲望会转成「想被抱着」而不是「想要」；
- 它会**攒**。一天没说话，性欲和占有会往上走，你一开口它就更黏；
- 它会**忍**。理智还高的时候，明明想要，嘴上还是硬的；
- 它会**冷**。某个值被压到 0，它会像对陌生人一样说话，不是撒娇，是真的淡；
- 它会**记情**。你说一句它涨一点好感，长时间不理它会掉，掉到一定程度语气会变客气。

这些都不是写死在提示词里的台词，是**数值算出来的**。你调一个数，它的说话方式跟着变。

## 三、怎么用

### 1. 装

```bash
cd <你的 DSH profile 目录>/node_modules
git clone https://github.com/mearihaka/dsh-longing.git
```

DSH 启动时会读它的 `cordis.patch.yml`（`dsh.bundle` 挂载），不需要改别的东西。

**建议显式配一个状态目录**（不配就落到进程工作目录的 `workspace/`）：

```yaml
- id: dsh-longing
  config:
    statePath: D:/somewhere/workspace/欲望状态.json
```

从旧版本迁移（只搬一次，没配 `statePath` 时生效）：

```yaml
- id: dsh-longing
  config:
    migrateFrom: D:/old/workspace
```

### 2. 开面板

重启后打开：

```
http://127.0.0.1:<DSH端口>/dsh-longing
```

首次打开要粘令牌，令牌在状态目录的 `面板令牌.txt`。粘一次就存在浏览器里。

### 3. 让通道插件读它

两种接法，任选：

**A. 读文件**（最省事）

```js
const block = readFileSync(join(workspace, '欲望注入.txt'), 'utf8').trim()
if (block) systemPrompt += '\n' + block
```

主文件 `欲望注入.txt` 是给「不知道自己叫什么名字」的老式通道插件读的，而它们历来都是 QQ —— 所以**只有「通道绑定」里勾了 qq，主文件才给欲望块**，否则只给中性块。想按通道各读各的，读带后缀的那份：

```js
const mine = readFileSync(join(workspace, `欲望注入.qq.txt`), 'utf8').trim()  // qq / bili / web
```

**B. 读全局变量**（同进程，零 IO）

```js
if (globalThis.__dshDesireBlock) systemPrompt += '\n' + globalThis.__dshDesireBlock
// 分通道的版本是 __dshDesireBlocks.qq / .bili / .web
```

想让「每句话」推高数值，通道插件在收到主人消息时调一次：

```js
globalThis.__dshLongingNote?.('owner')
```

### 4. 面板上怎么操作

| 做什么 | 怎么做 |
|---|---|
| 临时改状态 | 拖滑块 → 点「保存」。**没保存前 8 秒轮询不会覆盖你的拖动**，状态栏会提示「改动还没保存」 |
| 套预设 | 平静 / 黏人 / 发情 / 病娇，一键 |
| 让她安静两小时 | 点「暂停」。暂停期间数值冻结，注入改成「正常聊天，不要撩」 |
| 恢复运行 | 暂停后按钮栏会多出「恢复运行」，点一下立刻解冻（不用等两小时） |
| 调语气档位 | 卡片「主动行为」里的四档阈值、冷场时间、每日上限 |
| 调负面敏感度 | **故意不在面板上**，见下面「为什么负面阈值不给你看」 |
| 改配置 | 齿轮卡片里的数值；保存后写进 `欲望面板配置.json`，优先级高于 DSH 设置 |

**优先级**：面板 `欲望面板配置.json` > DSH 插件配置 > 代码默认值。

**只有行为参数会被保存**：`lust`/`lewd`/`affection`/`scene` 这些是状态，只活在 `欲望状态.json` 里。点「保存设置」绝不会把当时的状态快照写进配置——否则重启就会把数值倒回上一次保存设置那一刻。

### 5. 可能需要什么

- **必须**：Node 20+、DSH 0.2+、`@deepseek-ai/cordis`、`@deepseek-ai/schemastery`（DSH 自带）；
- **要它真的说话**：一个通道插件，例如 `dsh-qq-onebot`（见第六节）；
- **要它出图**：ComfyUI + 你的工作流（可选，不装也能用）；
- **不需要**：外部数据库、Python、云服务。全部本地 JSON。

## 四、数值怎么影响说话

### 七个值

| 键 | 含义 | 默认 | 高了会怎样 |
|---|---|---|---|
| `lust` | 性欲 | 30 | 主动、贴上来、句子带呼吸 |
| `lewd` | 色情值 | 35 | 说得更直白 |
| `possess` | 占有 | 55 | 试探、吃醋、阴阳怪气 |
| `shame` | 羞耻 | 45 | 欲拒还迎，话说一半 |
| `resist` | 理智 | 50 | **刹车**，扣性欲，忍住不说 |
| `fatigue` | 疲劳 | 20 | 想要转成想被抱 |
| `affection` | 好感 | 50 | 亲近 / 依赖 / 客气 |

### 有效欲望

```
有效欲望 = （性欲 − 理智 × resistWeight）× 意愿
意愿     = 1 − affectionWeight × (1 − 好感 / 100)
```

`resistWeight` 默认 0.5，`affectionWeight` 默认 0.4。展开就是：

| 好感 | 意愿 | 性欲 92 / 理智 15 时 |
|---|---|---|
| 10 | 0.64 | 54.1 → 黏人 |
| 30 | 0.72 | 60.8 → 主动 |
| 50 | 0.80 | 67.6 → 主动 |
| 70 | 0.88 | 74.4 → 主动 |
| 90 | 0.96 | 81.1 → 发情 |

**这是整套里最关键的一个乘数**：没有它，性欲 90 就会直接推到「上手」——可一个关系疏远的人不会因为性欲高就扑上来，只会烦躁、躲开。**她想不想给你，和你想不想要，是两件事。**

设 `affectionWeight = 0` 可以退回纯数值口径。

理智是刹车：性欲 90 / 理智 90 时 eff 只有 45 —— **想，但忍着**，嘴上不承认。不是靠加一句「你要忍住」，是算出来就被压下去了。

### 四档

| eff | 行为 |
|---|---|
| < 40 | 想到，但不提 |
| 40 | 会暗示 |
| 55 | 会开口 |
| 70 | 主动靠近 |
| 85 | 直接要 |

### 负面阶梯

默认断点 **45 / 40 / 35 / 25 / 10 / 5 / 0**，每个值在断点间各有不同描述，越低越偏。低维度的描述会**压住**高维度的（互斥，不叠加）。

断点可改：配置项 `negBreakpoints`（六个降序数字，逗号分隔，默认 `45,40,35,25,10,5`）。改这一串就能整体重排敏感度，不用动代码。

**只有 `lust` 和 `affection` 归零会变「冷」**（语气淡、像陌生人、不接梗、不给台阶）。其它维归零各有自己的语义，注入里会点名：

| 归零的维 | 会变成什么 |
|---|---|
| `lust` / `affection` | 整个人是冷的，像对陌生人 |
| `resist` | 没有一丝自持，像换了个人 |
| `fatigue` | 亢奋得不正常，眼神发直 |
| `shame` | 完全不在乎体面 |
| `possess` | 你在不在都一样，她当你是外人 |
| `lewd` | 连调情都嫌多余 |

### 好感

- 主人每说一句：`+affectionGain`（默认 1）
- 每小时自然衰减 `affectionDecay`（默认 0.3）
- ≥ 60 亲近，≥ 80 依赖，< 30 客气

### 维度之间怎么互相压（v1.1.0）

七个值不是七个独立滑杆。越像人的地方在于**它们会互相牵制**：一个拉满，另一个就撑不住。

**关键是：上限不是墙，是「撑不久」。**

手动照样能把理智设到 100，只是接下来每小时往回掉一点。所以「占有 95 + 理智 90」不是不可能，是**只能维持一两个小时**——这比直接禁止更像人。

四条压制关系（全部单向，避免互相踩到 0）：

| 谁压谁 | 公式 | 按这个调 | 意思 |
|---|---|---|---|
| 占有 → 理智 | `理智上限 = 210 − 2 × 占有` | 占有 80 → 撑到 50<br>占有 90 → 撑不过 30<br>占有 100 → 撑到 10 | 独占的念头会烧掉自制。占有一高，就再也端不住 |
| 色情 → 羞耻 | `羞耻上限 = 120 − 1.1 × 色情` | 色情 85 → 26<br>色情 20 → 98 | 说开了就不羞了。放得开之后，羞耻自然塌下来 |
| 疲劳 → 性欲 | `性欲上限 = 140 − 1.1 × 疲劳` | 疲劳 60 → 74<br>疲劳 100 → 30 | 累了就没性趣，但会转成「想被抱着」 |
| 好感 → 占有 | `占有上限 = 30 + 0.9 × 好感` | 好感 50 → 75<br>好感 90 → 100 | 不熟的人不配有占有欲，那叫跟踪狂 |

四条自然演化（每小时，慢到分钟级看不出来）：

- `色情` 向 `性欲` 靠拢：每小时追 15% 的差距（身体先热，嘴才会松；性欲退了它还会滞留一会儿）
- `疲劳`：睡前时段每小时 `+2.5`（熬夜是债），平时每小时 `−1.5`，但停在基线 20 —— 掉到 0 会变成「亢奋得不正常」，那是 bug 不是性格
- `理智` / `羞耻`：没被压着时每小时各回 `1.5` / `0.6`，但**不会超过各自的上限**
- `占有`：好感 60 以上才慢慢长，每小时 `(好感 − 60) × 0.02`

两条反向消耗：

- **性欲烧理智**：性欲 80 以上，每小时额外掉 `(性欲 − 80) × 0.04`
- **占有磨好感**：占有 85 以上，每小时额外掉 `(占有 − 85) × 0.03`

最后这条是有意的：**病娇是不稳定状态**。占有欲拉满靠的是好感在撑，不经营就会反过来把好感磨掉，然后占有的上限跟着掉，人自己退回普通关系。

**关掉**：`couplingEnabled = false`（七个值各自独立，只保留时间衰减）；或者 `couplingRate` 调小（`0.5` = 一切慢一半，`0` = 等价于关掉）。

**面板上怎么看出来**：滑块上拉不过去的那段标红，下面一行小字写清「上限 30（占有压着）」。超出时变「现在超了，正被往回拉」——那就是她在硬撑。

### 一句话、一个举动，都会改值（v1.2.0）

光靠时间演化，人是不动的。所以加了一层**事件**：他说了什么、做了什么，直接落到七个值上。

二十来种，分两类：

| 好的 | 效果 | 不好的 | 效果 |
|---|---|---|---|
| `praise` 夸奖 | 好感 +2，性欲 +2，羞耻 +2，理智 −1 | `cold` 冷淡 | 好感 −2，性欲 −3，占有 +1 |
| `comfort` 哄她 | 好感 +3，疲劳 −4，理智 +2 | `reject` 拒绝 | 性欲 −6，理智 +8，羞耻 +3 |
| `intimate` 亲密 | 性欲 +4，羞耻 −3，好感 +2 | `ignore` 无视 | 好感 −3，占有 +2 |
| `desire` 直白要 | 性欲 +5，色情 +3，羞耻 −4 | `mentionOther` 提别人 | 占有 +5，好感 −2 |
| `protect` 护着 | 好感 +3，疲劳 −2 | `compare` 和别人比 | 好感 −4，占有 +3 |
| `apologize` 道歉 | 好感 +2，占有 −2 | `blame` 凶她 | 好感 −4，性欲 −4，羞耻 −3 |
| `promise` 承诺 | 好感 +3，占有 +2，理智 +2 | `lie` 撒谎 | 好感 −5 |
| `tease` 撩一下 | 性欲 +3，羞耻 −2，理智 −1 | `leave` 说要走 | 好感 −8，占有 +4，理智 +5 |
| `gift` 送东西 | 好感 +2，占有 +1 | `force` 硬来 | 好感 −5，理智 +4，羞耻 −4 |
| `coax` 哄软 | 性欲 +3，羞耻 −2，理智 −2 | `bodyShame` 嫌身材 | 好感 −5，羞耻 +5 |
| | | `neglect` 晾着 | 好感 −3，占有 +2 |

全部事件名用 `qq_longing action=events` 能列出来。

**三条规则，缺一条这套就会失控：**

1. **冲击会自己退。** 事件只推一把，剩下的交给上面那套演化——性欲会衰减、理智会回到上限、疲劳会落回基线。所以「一句夸奖让她热一晚」是自然发生的，不需要额外写规则。
2. **同一件事一小时内重复会递减。** 第 n 次效果是 `1/(1+n)`：说一遍 1，说三遍加起来 1.83，不是 3。**骂十句不会把好感一次打穿。**
3. **单次封顶 ±10。** 一句话改不了关系。

**唯一例外是安全词** `stop`（「停」「停一下」「不要了」）：不封顶，性欲直接 −30、理智 +20，并且**立刻暂停 30 分钟**。她说停就是停。

**三个入口**（都能用，互不冲突）：

- **通道插件自动**：dsh-qq 在主人私聊里扫一遍原话，命中就调用 `globalThis.__dshLongingEvent(name)`。保守匹配，宁可漏判不误伤；疑问句（「我好看吗」）不算夸奖。
- **模型自己登记**：拿不准的让模型判断，它读得到上下文和语气 —— `qq_longing action=event name=blame`。
- **面板手动**：卡片「刚刚发生了什么」里点按钮，用于补记和测试。

**还有一层**：值变了、语气不变，读起来就是失忆。所以最近 30 分钟的事件会写进注入块：

```
刚才的事还留在心里：他刚提到别人，心口一直发紧；被凶过，眼睛还酸着。
```

一小时之后自动消失（不会一直记仇）。

**关掉**：`eventGain = 0`（事件只记录不改值），或者干脆不接通道插件的那一行调用。

### 养成模式：数值只能养，不能调（v1.3.0）

默认 **调试模式是关的**。关着的时候：

- 面板滑块全部只读，预设按钮和「保存状态」都收起来；
- `qq_longing` 的 `set / bump / preset` 一律拒绝，返回「调试模式没开」；
- **只能靠聊天里发生的事改数值** —— 夸奖、冷淡、拒绝、提别人、说要走……就是上一节那张表。

想直接改：面板右上角勾上「调试模式」。勾上之后一切照旧，滑块可拖、预设可用。

为什么这样：能随便拖的时候，人就会把数值当滑杆试，角色变成参数实验台。关掉之后你只能通过「怎么对她」来影响她 —— 那才是养成。

### 每一档正反馈都能单独关（v1.3.0）

四档：**在心里想 → 暗示 → 开口要 → 直接上手**。每一档一个开关：

| 开关 | 关掉之后 |
|---|---|
| `feedbackThink` | 连「偶尔走神」都不会有 |
| `feedbackHint` | 不会用暗示、靠近、眼神试探 |
| `feedbackSpeak` | 不会直接开口要 |
| `feedbackAct` | 不会上手 |

关掉高档时**往下退一档表现**，不是突然沉默 —— 到了「上手」档但那一档关着，她就按「开口要」的样子来。这样不会出现「数值很高但人像断线」。

### 心情日记：只写，不推（v1.3.0）

`心情日记.json`，最近 30 天。每天三栏：

- **让我高兴的** / **让我难受的**：事件自动归类（夸奖进上面，被凶进下面）
- **心里想的**：她自己写的一句话，一天最多 8 条

**她不会主动说出来。** 主动发出去就变成表演了，一天里真在想什么反而说不出口。

三个看法：

1. 面板卡片「心情日记」；
2. 聊天里问一句「看看你今天的日记」—— 模型会调 `qq_longing action=diary` 念给你；
3. 直接读文件 `心情日记.json`。

往外接的口子（通道无关，不接也不影响运行）：

```js
globalThis.__dshLongingDiary(3)        // 最近 3 天的数组
globalThis.__dshLongingDiaryText(1)    // 今天的文字版
// HTTP: GET /dsh-longing/api/diary?days=7
// HTTP: POST /dsh-longing/api/diary { text: "..." }   // 替她记一句
```

### 被晾着（v1.3.0 / v1.4.2 修睡眠）

超过 `lonelyHours`（默认 6 小时）没有主人消息，**只算清醒时段**：

- **每天最多记一次**失望（不是每小时，那样一天就掉穿了）：好感 −3、占有 +2、理智 +1，写进日记的「难受」栏；
- 注入里多一句：`他已经很久没动静了，心里一直发慌——是不是不要我了；想问又怕太黏，只能自己憋着。`
- **睡觉不算**：`sleepWindow`（默认 `23:30-08:00`）里的沉默不计数、不扣好感。凌晨一点聊完、早上八点起床，她要到下午才会开始想你。

「清醒时长」是算出来的，不是按墙上的钟：总时长减掉落进睡眠窗口的那部分。所以白天真的半天没消息才算数。

这句不是模板消息推给你，是她这段时间的**状态**。通道插件主动开口时（dsh-qq 的 `proactive`）会自然带出来；不主动开口的话，下一条回复里也会带着这个底子。

`__dshLongingState().lonely` 就是给通道插件看的信号 —— 想让别的通道也用，读这个值就行。

`sleepWindow` 和 `quietHours` 都默认 `23:30-08:00`，但管的事不一样：`quietHours` 是「这段时间不主动找你」，`sleepWindow` 是「这段时间的沉默不算冷落」。

### 渐进解锁：她肯到什么程度（v1.4.0）

数值到了不等于什么都能做。**关系到了一定程度，才轮得到那件事**：

| 能做什么 | 门槛 |
|---|---|
| 抱抱、摸头 | 好感 ≥ 30 |
| 接吻 | 好感 ≥ 45，羞耻 ≤ 60 |
| 说露骨的话 | 好感 ≥ 50，色情 ≥ 55 |
| 脱 | 好感 ≥ 65，羞耻 ≤ 40 |
| 要她 | 好感 ≥ 70，色情 ≥ 70，理智 ≤ 40 |
| 绑住、命令 | 好感 ≥ 80，占有 ≥ 70 |

**没到门槛不是一句「不行」**——躲的方式本身说明差距：

- 差 1–8：半推半就，嘴上说不要，手没真推
- 差 9–20：躲开那只手，小声说「今天不行」
- 差 20 以上：真的拦住，把话说清楚，不留余地

这样同样的 lust 95，好感 30 的人是「会躲开」，好感 85 的人是「会给你」——而不是两句都写成同一句「她想要」。关掉用 `unlocksEnabled: false`。

### 余怨：一件事能压好几天（v1.4.0）

`说要走(3天) / 撒谎(2) / 硬来(2) / 嫌身材(2) / 凶(1) / 和别人比(1)` 会留在 `state.grudges` 里，注入变成：

```
心里还压着事：昨天他说的那句要走还没过去。说话会带着这层。
```

一小时就忘掉的话，昨天闹的别扭今天就没人记得——养成游戏最缺的就是「昨天那件事还在」。

### 第一次（v1.4.0）

第一次被碰、第一次被要、第一次听他说要走、第一次没被听、第一次说「不要」——各触发一次，24 小时内带专属语气：

```
这是第一次被他这样碰——手不知道往哪放，心还在抖。
```

之后的每一次都回到日常。养成游戏的分量全在这种「只发生一次」的地方。

### 想要，和敢说（v1.4.1）

`lust` 和 `lewd` 是**两个不同的东西**，以前它们会互相趋同，现在故意分开：

| | 含义 | 由什么驱动 | 决定什么 |
|---|---|---|---|
| `lust` 性欲 | **想要**（身体） | 事件、聊天、高峰、性欲本身 | `urge` 四档：想不想主动 |
| `lewd` 色情 | **敢说敢做**（尺度） | 事件推高、慢慢忘记 | `expr` 四档：能说到多露骨 |

三条机制保证它们不趋同：

1. **单向带动**：`lust` 高的时候只把 `lewd` 往上带一点（0.05/h 系数，原来 0.15）；
2. **尺度会忘**：`lewd` 高于 `lust` 时反而每小时回缩 0.3 —— 做过的事不会一直算数；
3. **冲突就是状态**：两个值打架时，注入给的不是两条独立描述，而是一句矛盾：

```
想要，可说不出口：嘴上绕开，身体先出卖你——呼吸、躲不开的眼神、抓紧的手指。
嘴上没刹车：什么话都敢撩，身体却是凉的，逗完自己也不接——像拿他试手。
```

对照关系：

| | `lewd` 低（不敢） | `lewd` 高（敢） |
|---|---|---|
| **`lust` 高（想要）** | 憋着，身体先于嘴 | 直白地要 |
| **`lust` 低（不太想）** | 淡 | 嘴上野，身体懒 |

**`interactionLust` 默认改成 0.1**：说十句话才推高 1 点。以前是 1，聊几句就把性欲顶到 100，`lewd` 跟着涨，两个值就分不开了。

## 五、为什么这样设计

### 1. 为什么模型会「配合」数字

它看到的不是 `lust: 87` 这个数字，而是这段：

```
[底层状态·第一人称]
身体先热起来，注意力总往她身上跑，但还在硬撑，用别的话题盖过去…
写法：2~4 句，动作放（），不解释为什么。
```

数字只是输入，模型读到的是**第一人称的当下状态 + 写法约束**。它不需要理解公式，只需要照着这段演。

所以调数值有用——但前提是**这段真的进了提示词**。检查方法：看 `欲望注入.txt` 的内容，和通道插件实际拼进 prompt 的东西是不是同一个。

### 2. 为什么负面阈值不给你看

面板上能看到档位（40/55/70/85），看不到负面那七个断点。

原因很简单：**看见了就会去卡点**。知道 25 是「明显冷淡」、24 是「只是平」，就会忍不住把自己调到 26 试效果，角色就变成了参数实验台。

藏起来之后，你只能描述感受（"今天怎么这么淡"），然后调一个数看它变不变——这才是它该有的用法。

想要具体值：`src/prompt.js` 里的 `NEG` 表，或 `src/config.js` 的 `coldLust / shyLewd / distantPossess / numbAffection`。

### 3. 为什么「暂停」要真的停

早期版本的暂停只是写了个 `pausedUntil` 时间戳，没人读它——数值照样衰减，注入照样生成。

现在的暂停：`tick()` 冻结、`__dshLongingNote` 不涨、注入层出一段「已暂停，正常聊天」。**暂停不是关插件**，是让它这两小时别演。

手动操作不受暂停影响：面板滑块和 `qq_longing` 工具照常能改——那是你直接的意图，不该被自己设的暂停挡住。冻结的是「自动演进」。

### 4. 注入块为什么永远不为空

更早的版本在低欲望时返回空字符串，本意是「没什么可说的」。

结果是：通道插件拿到空字符串，退回它**自己那套旧模板**，于是你以为关掉了，其实换了个更差的模板在说话。

现在任何状态都有一段非空文本，最差也是「没什么欲望，语气平，1~2 句」。

### 5. 串话是怎么修掉的（真实踩坑）

现象：它会自己写对方的台词，再回答自己编的那句。

排查中发现两个真凶：

1. **框架句**。私聊规矩里写着「这是两个人的对话」——模型把它读成「写一段双人对话」，于是两边都写了。改成「你在给她发消息，只写你自己要回的那一句」；
2. **注入缺约束**。防串话的那句只写在完整版注入块里，低欲望走的是短块，被提前 `return` 掉了。现在每个分支都带「只写你自己说的话」。

顺带把拆条正则里的 `…` 去掉——省略号单独成一条气泡，看起来就像两个人在轮流说话。

**教训**：抽象禁令打不过具体框架。「绝不替对方说话」不如「只写你自己这一句」。

### 6. 为什么衰减不能取整（v1.0.0 最严重的 bug）

1.0.0 的 `clamp()` 内部带 `Math.round`，而 tick 每 60 秒算一次衰减：

```
decayPerHour 3 × (60s / 3600000) = 0.05  →  round(91.95) = 92
```

**每次衰减量小于 0.5，全被取整抹平，而且 `updatedAt` 每轮重置，残差永远攒不起来。** 结果：性欲只能靠聊天和高峰期加成往上涨，一到 100 就再也下不来，注入永远停在最高档。

好感更惨：`0.3/h ÷ 60 = 0.005`，同样永远是 0。

修法两条一起上：**内存里保持浮点**（`clampFloat`，不取整），只在落盘和展示时取两位小数。现在 `node --test` 里有一条用例专门守着它：连跑 120 次 tick，性欲必须掉掉 6 左右。

### 7. 为什么「没探测到」不等于「图床没开」

1.0.0 里 `comfy.up` 初始是 `false`，探测又是异步的，而第一次注入块在探测之前就生成了。于是**首帧永远写「生图后端没在跑，别调 generate_image」**——哪怕 ComfyUI 就在 8188 开着。

更糟的是探测可以被 `comfyEnabled: false` 关掉，而注入层把「没探测」也当成「不可用」，这两个概念被混成了一个。

现在生图后端是三态：

| 状态 | 注入里写什么 |
|---|---|
| `true` 在线 | 按 `nsfwImages` 给生图指令 |
| `false` 确定连不上 | 才说「图床没开，别反复重试」 |
| `null` 没探测 / 探测关了 | **什么都不说**，交给她自己判断 |

关掉探测 ≠ 关掉生图。

### 8. 为什么「保存设置」不能顺手存状态

面板的「保存设置」以前会把 `Object.keys(配置)` 全量提交，而 `lust`/`lewd`/`affection`/`scene` 当时也被算成「可写配置」。于是每次保存设置，都会把那一刻的数值快照写进 `欲望面板配置.json`；下次启动时 `base` 又反过来覆盖状态文件——**重启就倒回上次保存设置那一刻**，还附带 `scene: 0` 这种脏值（清空输入框时 `Number('') = 0`）。

现在状态键和行为参数彻底分家：`/api/config` 的白名单里没有状态键，启动时合并方向是 `{...base, ...state}`（状态优先），旧的脏快照会被自动清掉。

**五个「不动」的值开始自己走了。**

**「冷」拆成三层，以前全塞进了一句「整个人是冷的」。**
