# dsh-longing（暗涌）

给 DeepSeek Harness 加一层「欲望状态」：性欲 / 色情 / 占有 / 羞耻 / 理智 / 疲劳，随时间衰减、睡前走高，并按状态影响角色的说话与主动性。

**插件本身不绑定任何聊天平台**。它只做三件事：维护状态、渲染面板、生成一段可以直接拼进系统提示的文本。谁来收发消息，由你自己接。

## 它是什么

- 一个 DSH 插件（`dsh.bundle` 挂载）：状态、衰减、高峰、面板、注入文本；
- 面板由插件自己用 DSH 的 `webServer` 提供：`http://127.0.0.1:<DSH端口>/dsh-longing`
- 状态文件 `欲望状态.json`（纯文本，可手改），路径默认 `workspace/`，可配置。

## 六个值

| 键 | 含义 | 默认 |
|---|---|---|
| `lust` | 性欲：多想要、多主动 | 30 |
| `lewd` | 色情值：露骨程度 | 35 |
| `possess` | 占有值：病娇浓度 | 55 |
| `shame` | 羞耻度：越高越欲拒还迎 | 45 |
| `resist` | 理智：越高越克制 | 50 |
| `fatigue` | 疲劳：高时欲望转成想被抱 | 20 |

`lust ≥ 40` 进入亲密语气，`≥ 60` 主动，`≥ 80` 发情。

## 三种接入方式（选一个就行）

### 1. 读文件（最省事，不写代码）

插件每分钟把当前该注入的文本写到：

```
<状态目录>/欲望注入.txt
```

你的 bot 插件只要在拼系统提示时读这个文件拼进去即可。空文件 = 当前不该注入（欲望低 / 暂停 / 时段外）。

```js
const block = readFileSync(injectPath, 'utf8').trim()
if (block) systemPrompt += '\n' + block
```

主动开口也可以走文件：面板里把「主动通道」设为 `file`，她会把要说的话追加到 `待发消息.txt`，你的 bot 轮询取走发送。

### 2. 取服务（插件作者）

```js
const desire = ctx.get('desire')
if (desire) {
  systemPrompt += '\n' + desire.block()
  const s = desire.state()   // { lust, lewd, ... }
}
```

### 3. 直接发（OneBot HTTP）

面板里「主动通道」选 `http`，填 OneBot HTTP 地址和 token、主人 ID。她会自己调 `/send_private_msg`。

## 面板

由插件自带，打开：

```
http://127.0.0.1:<DSH端口>/dsh-longing
```

首次打开要粘贴令牌，令牌在状态目录的 `面板令牌.txt`（只在本地）。

面板里能改：六个值、场景、高峰时段、衰减、主动参数、通道、生图后端、人设补丁、安全设定（只对主人生效、安全词、暂停）。

**优先级**：面板 > DSH 插件设置 > 代码默认值。被面板覆盖的字段会有橙边，点「恢复默认」清空覆盖。

## 生图后端（可选）

面板里可以配 ComfyUI 地址、启动脚本、自动拉起。探测不到时不会报错，注入文本会改成「图床没开」，聊天照常。

## 配置

DSH 插件设置里能改全部字段（见 `src/config.js`）；面板改的值优先。


## 注意事项

### 1. 成人内容要你自己解锁

本插件本身**不生成成人内容**，它只维护状态、生成提示词块。真正的露骨输出、成人向生图，取决于你装的模型和后端：

- 有些模型/渠道默认有内容过滤，插件管不了；
- 要放开，需要你自己处理（换模型、去皮、本地推理等），仓库不提供、也不针对任何具体平台；
- 开了成人向之后，图也会走你配置的生图后端，责任和风险都在使用者这边。

### 2. 和 dsh-qq 的冲突

如果你同时装了 `dsh-qq-onebot`：

- **主动说话会双发**。dsh-qq 有 `proactiveEnabled`（默认开），本插件也有主动开口。二选一，别同时开；
- **注入可能重复**。dsh-qq 自己也会拼一段欲望提示，本插件再拼一次会让模型收到两份状态。建议只保留一处；
- 本插件不修改 dsh-qq 的任何文件，升级 dsh-qq 不会冲掉本插件。

### 3. 面板令牌是本地凭证

- 令牌写在状态目录的 `面板令牌.txt`，**只在本机有效**；
- 不要把它提交到仓库、贴到群里、发到截图里；
- 面板只接受 `Origin` 与自身同源的请求，但**同一台机器上的其他程序仍能读到令牌文件**。

### 4. 状态文件是明文

`欲望状态.json`、`欲望历史.json`、`欲望注入.txt` 都是明文，包含亲密偏好。放在本机没事，**别同步到网盘或公开仓库**（`.gitignore` 已排除运行期文件，但你自己复制时要注意）。

### 5. 主动开口可能被平台判定为骚扰

- 默认关闭；
- 开启后请设置合理的冷场时间、每小时上限、安静时段；
- 平台对机器人主动私聊有风控，频率过高可能被限制或封号。

### 6. 本插件不绑定任何聊天平台

它只写 `欲望注入.txt` 和暴露 `ctx.get('longing')`。要让它真的说话，需要你用的通道插件去读文件或取服务。没有通道插件时，它只是一个面板 + 状态文件。

### 7. 代码风格与兼容性

- 纯 JavaScript（ESM），无运行时第三方依赖；
- 需要 Node 20+、DSH 0.2+；
- 只测过 Windows，路径处理用了 `fileURLToPath`，其他平台理论可用但未验证。

## 隐私

- 状态、历史、注入文本都是明文 JSON/文本，放在本机；
- `.gitignore` 已排除运行期文件；
- 面板有令牌 + Origin 校验，只绑回环地址。
